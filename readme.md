# Chef Player - Recipe Rush (Egypt Edition)
This game is a food-related game, where you as a chef, must deliver orders to customers (represented by emojis) or cook freely and let the system decide and feedback your new dish invention!
## Features
Egyptian Food -> Mahshi, Koshary, Taamiya and etc...

Feedback System -> You cook freely and let system decide whether it's safe to eat and real or not :skull:

Funny Images and Gifs -> represents the moves or actions (food, stir, cook, bake etc...)
## Installation (if you want to play offline!)
Just download the zip and unzip it then open index.html and have fun!
## additional info
There is a lot of funny interactions and feedbacks from the system when you play in free mode!

Making a lot of faults breaking the timer bar in the order (but still working below the pan so don't try to break the system!)
